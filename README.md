# teamproject

예술인경력정보시스템 홈페이지 리디자인 2안의 정적 웹 구현입니다. 공식 운영 사이트가 아닌 팀 프로젝트입니다.

## 실행

별도 설치·빌드 없이 `index.html`과 자산을 정적 서버에서 제공합니다. 예: `python -m http.server 4173` 실행 후 `http://localhost:4173`에 접속합니다. GitHub Pages에서는 저장소 루트의 `main` 브랜치를 배포 대상으로 설정합니다.

## 디자인

- 1920px 화면 기준 콘텐츠 1560px, 좌우 여백 약 180px
- 데스크톱 주요 섹션 사이 150px, 작은 모바일 화면은 80px
- Pretendard Regular / SemiBold / Bold (OFL, `assets/fonts/LICENSE.txt`)
- 제목 44px, 카드 제목 28px, 본문·버튼 22px, 히어로 제목 72px
- 포인트 `#FFC624`, 라이트 `#FBF8F3`, 다크 `#0E0B09`
- 아이콘 `#3F5660` / `#BCCCD2` 투톤

## 동작

히어로의 첫 다섯 사진은 **조각 → 공예 → 무용 → 첼로 → 가수**입니다. 4.5초마다 왼쪽으로 한 장씩 이동하며 회화 사진을 포함한 여섯 장을 순환합니다. 이전·다음·일시정지, 마우스 오버/키보드 포커스 중 일시정지, 비활성 탭 중 정지, 운영체제 동작 줄이기를 지원합니다. `app.js`의 `artists` 배열에서 사진을 추가할 수 있습니다.

라이트/다크 전환, 모바일 메뉴, FAQ 검색·펼치기, 하위 안내 화면을 제공합니다. 신청은 로컬 시연 로그인으로 연결하며, 실제 가입·개인 조회·외부 지원사업은 공식 사이트로 안내합니다. 실제 계정 정보와 개인정보를 수집하지 않습니다.

실시간 신청현황 API와 공지 데이터는 연동하지 않았으며 숫자는 대시로 표시합니다. 영상 카드 이미지는 자체 안내 그래픽이며 클릭하면 공식 영상 안내 페이지로 이동합니다. 사진은 AI 생성 이미지이며 원본 사진 스트립을 CSS로 잘라 보여줍니다.

## 파일

`index.html`: 구조·콘텐츠 / `styles.css`: 디자인·반응형 / `app.js`: 링크·캐러셀·메뉴·테마 / `assets`: 이미지·아이콘·폰트



## 전체 사이트 디자인 확장

홈 외에 제도안내, 신청방법, 절차, 분야별 기준, 영상, 복지지원, 권익보호, 공지 목록·상세, FAQ 검색·분류, 이용안내 및 개인 서비스 연결 화면을 추가했습니다. 상단 호버 메뉴·하위 메뉴·좌측 메뉴·탭으로 연결합니다.

`site-data.js`는 2026-11-25 공식 공개 페이지에서 확인한 정보 스냅샷입니다. 공지 10건의 제목·등록일·본문·첨부 링크와 FAQ 13건을 담고 있습니다. 전체 과거 공지는 공식 게시판 링크로 이어집니다. 실시간 데이터 연동은 하지 않습니다.

실제 로그인·회원가입·개인 신청·개인 조회와 외부 전문 서비스는 공식 시스템 링크를 제공합니다. 로컬 로그인·신청 화면은 아래의 시연 계정과 예시 정보로만 체험하며 실제 인증이나 접수를 수행하지 않습니다.

분야별 기준은 일반·신진·특례 유형과 15개 분야 선택으로 정리했습니다. 영상 페이지는 공식 YouTube 영상 10개에 제목을 붙여 연결합니다. 정보 원문과 확인 날짜를 각 하위 화면에 표시합니다.

추가 파일: `site.js` (메뉴·페이지·검색), `pages.css` (하위 화면·호버·아이콘), `site-data.js` (공식 정보 스냅샷).


## 화면 정돈 업데이트

1560px 그리드에 맞춰 사진과 텍스트를 확대했습니다. 상단 유틸리티는 18px이며 다크 모드는 달·해 아이콘을 사용합니다. 메뉴의 꺾쇠와 드롭다운 중복 제목을 제거했습니다. 로고는 하위 화면에서 홈으로 이동하고 홈에서는 상단으로 이동합니다. 버튼 호버는 배경·글자색만 변경하며 이동·그림자 효과를 사용하지 않습니다. 데스크톱(1920px)·모바일(390px)에서 42개 경로의 가로 넘침이 없음을 확인했습니다.


## 로그인·신청 흐름과 안내 화면 정리

비로그인 상태에서 예술활동증명 신청을 누르면 `#/guide/login?next=cert%2Fapply`로 이동합니다. 로그인 화면은 아이디·비밀번호 입력, 보기 전환, 필수 입력 안내, 공식 계정 찾기 링크를 제공합니다. **실제 인증이 없는 디자인 시연**으로, 표시된 `artist / demo1234!` 계정 또는 시연 버튼으로만 체험합니다. 브라우저 세션에는 시연 로그인 여부만 저장하며 비밀번호와 신청서는 저장·전송하지 않습니다.

시연 로그인 후 신청 정보 → 활동 자료 → 내용 확인으로 이동하며, 마지막 화면에 실제 접수가 되지 않았음을 표시합니다. 실제 신청은 공식 사이트 링크를 이용합니다.

제도안내와 신청방법 화면은 1차 시안의 항목·표 구성에 맞춰 정돈했습니다. 큰 안내 이미지를 제거하고 주제 사이 여백, 항목명과 설명의 정렬, 표의 행 간격을 통일했습니다. 확인된 안내 원문 링크는 유지합니다.

## 푸터 정리

따뜻한 회색 배경에 예술활동증명·복지지원·권익보호·알림의 4열 사이트맵을 배치했습니다. 기관 정보, 이용정책과 맨 위로 버튼을 제공하며, 히어로의 신청·조회·출력 버튼은 가운데 정렬로 통일했습니다.
